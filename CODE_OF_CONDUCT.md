# Code of Conduct

Be kind and useful.

Disagreement about a patch is fine. Personal attacks, harassment,
discrimination, threats, and publishing someone's private information are not.
Keep review comments about the code and the trade-off at hand.

If something crosses that line, email `juanpedrosugg+github [at] gmail [dot] com`.
Reports will be handled privately and fairly. Repeated or serious abuse may lead
to removal from project spaces.
